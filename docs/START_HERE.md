# 先读这份：你拿到的是什么

你想做的是自己的海洋知识服务。这个仓库把阅读入口和完整编辑引擎都放在你的项目里，后续可以继续交给开发者或 AI 改，不需要把 stepx 当作唯一入口。

## 从最容易用的部分开始

双击根目录“打开海洋阅读.cmd”，它会立即在本机打开已有资料。想收取新资料时，另双击“更新订阅.cmd”，结束后刷新阅读页。电脑上的服务只允许这台电脑访问；不是别人可以直接访问的网站。使用前需要 Python 3.11+，更新订阅时需要联网。

阅读页可以按海洋方向筛选、搜索和收藏。收藏保存在当前浏览器的本机空间，换浏览器、清理站点数据或换电脑后不会自动同步。它不需要手机号、会员或付款。

首页默认显示已整理的中文标题和一段概括，点击标题直接打开原文。本轮221条资料全部完成中文整理：44条依据论文摘要、66条依据来源节选、111条仅依据标题；只有标题时会明确提醒查看原文方法与结果。这一步没有替你核对科研结论，也没有完成 AIHOT 的两次选稿评分。

“更新订阅”负责收取来源资料，不会自动调用 AI 翻译。已整理且内容未变的资料继续显示中文；新增或内容变化的资料进入待整理队列，默认隐藏，可勾选“也看待整理原文”查看。以后把项目交给 AI 助手，按仓库里的提示词继续整理即可，详见 [中文整理说明](CHINESE_READING.md)。

## 如果想让电脑关机后也更新

本次使用你提供的 [ocean-pool 公开仓库](https://github.com/liutianbabushuijue-web/ocean-pool)，按你最新选择公开代码和公开来源资料。Actions 是 GitHub 帮你执行更新脚本的地方，项目上传并实际运行后，仓库里的提交保存每次结果；电脑关机后也可以继续尝试更新。阅读仍从本机入口打开，需要先取得仓库中的最新资料。

按 [GitHub 使用说明](GITHUB_GUIDE.md) 查看上传后的更新方式。Pages 是另一项网页发布服务，本次保持关闭；公开代码仓库不会自动变成可供手机随时访问的阅读网站。

## 为什么同时保留完整引擎

完整 AIHOT 引擎会进一步判断内容是不是海洋行业新闻，让模型独立打两次分，再写中文内容、合并重复报道、形成热点与刊物。它需要模型 API、数据库、预算设置和持续运行，不能用一个静态网页替代。

海洋版已经替换信源配置、领域词表、评分和写作提示词。评分门槛尚未用你自己的标注样本校准，先保留人工核对。需要升级时，从 [代码地图](AIHOT_MAP.md) 和 engine/README.md 开始，不必推倒轻量阅读站。

本机运行工具的历史验收只证明独立环境能启动、停止、备份及展示空资料；不代表真实模型、自动采集、日报和 stepx 推送已经跑通。

## 你平时只需要留意三件事

1. 看“上次成功更新”，不要把“刚刚尝试刷新”当作已经拿到新内容。
2. 看来源与原文日期，有疑问点开原文。没有日期就是未知，不能用抓取时间冒充发表日期。
3. 看来源状态。个别失败时可以继续看旧资料；长期失败的来源需要更换地址或人工处理。

上游代码和提示词可以帮助你理解方法，但不会附送卡兹克原站的真实用户、资料库、完整信源名单或运营成绩。这个海洋项目的质量要靠自己的来源和审核逐步积累。
