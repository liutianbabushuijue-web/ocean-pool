# 来源、RSS 与资料边界

## 信源和 RSS 分别是什么

信源是“哪家机构、期刊或团队值得关注”。RSS 是它们发布更新的一种格式；Atom是相近的订阅格式。一个来源可能提供 RSS，也可能只有网页或接口。

本版轻量脚本读取 config/sources.json。RSS/Atom 可以直接取更新，Crossref 项目通过接口读取；external 是待接入的外部采集来源，不会凭空长出文章。31项配置包括17个RSS、9个JSON/Crossref、5个中文 external。自动运行是否成功，要看每次实际来源状态。

## 原始订阅与精选

阅读页保留原文链接、英文原题和可得的来源摘要，同时显示本轮由 AI 助手生成的中文标题与一段概括。中文整理逐条注明依据：论文摘要、来源节选或只有标题。只有标题的资料不补写研究方法或结论；作者、单位或目录元数据不充当实质摘要，详见 [中文整理说明](CHINESE_READING.md)。规则相关性只是帮助筛选，不是模型评分、论文质量判断或审核结论。来源没有原文日期时保留未知；不能拿抓取时间填成原文时间。

完整引擎另外包含行业预筛、两次独立评分、事件归组与刊物流程，见 [代码地图](AIHOT_MAP.md)。本轮已完成的中文翻译和概括，不代表资料也已经通过完整引擎的选稿评分、归组或事实审核。

## RSS 也是输出

刷新脚本会写出：

| 文件 | 用途 |
| --- | --- |
| site/data.json | 阅读页显示的数据、来源状态及更新时间 |
| site/feed.xml | 已完成中文整理的资料合并订阅流，最多最新200条 |
| site/ocean-sources.opml | RSS来源目录，可导入其他订阅阅读器 |
| site/sources.opml | 兼容同内容的来源目录文件 |

OPML相当于来源通讯录，不是文章备份；RSS是后续更新流，也不是永久完整档案。导入OPML后，阅读器直接向各原始来源取资料，不经过本项目的规则筛选。Crossref接口和 external 任务不会冒充RSS加入目录。

## 直接订阅中文资料，或在本机阅读

把 [海洋中文 RSS](https://raw.githubusercontent.com/liutianbabushuijue-web/ocean-pool/main/site/feed.xml) 的链接加入自己的 RSS 阅读器，便可订阅本项目已完成中文整理的资料，最多保留最新200条。它通过公开的 ocean-pool 仓库提供原始XML文件，不需要先启用 Pages。GitHub 的文件预览页不是 RSS 服务地址，应使用上述 raw.githubusercontent.com 链接。

如果想直接追踪来源本身，可以下载 site/ocean-sources.opml 并导入阅读器；阅读器直接访问17个原始 RSS 来源，这些原始来源可能仍为英文，不经过本项目中文整理。本机阅读页则提供搜索、筛选和收藏。中文RSS、原始来源目录与本机网页是三种不同入口。

采集更新不会调用外部模型 API。中文结果仅在原题和来源短摘要的输入指纹一致时继续套用；新增或变更资料进入待整理队列，等待 AI 助手重新执行提示词。默认中文页及中文 RSS 不把尚未整理的英文原文混入。

## 订阅地址怎样保存，更新怎样到达阅读器

config/sources.json 已分别保存项目主页 projectUrl 和公开订阅地址 feedUrl。当前项目主页为本仓库，feedUrl 为上述原始XML地址；RSS自身也记录此订阅地址。文章链接仍直达各自原文，不会把文章点击引向GitHub代码页。

GitHub定时更新成功写回 site/feed.xml 后，阅读器下一次读取同一地址时取得新内容。抓到新原文不等于已经完成中文整理；尚未整理的条目留在待整理队列，不混入中文RSS。来源暂时失败时，已有中文资料仍可继续订阅。

以后如果发布自己的阅读网站，可以设置 siteUrl 或 OCEAN_SITE_URL；若希望RSS也改从该网站提供，再把 feedUrl 改为那个网站的实际 feed.xml 地址。项目型站点可能带仓库子路径，迁移时需保留。当前无需修改这些设置，就可以使用已提供的公开RSS地址。

## 更新失败会怎样

单个来源失败时保留先前资料并标记 stale，不把临时网络失败当撤稿。只有确实成功取到自动来源数据，metadata.lastSuccessAt 才前进；尝试时间与成功时间分开。

全部自动来源都失败时，脚本返回失败状态，保留旧资料与上次成功时间，同时记录本次错误。Actions可以保存这份错误状态，但不会因此把运行标为成功。网页上的更新日期和失败信息，比“定时器已配置”更能说明实际情况。

## 内容使用范围

软件MIT许可覆盖代码，不自动覆盖订阅内容的版权。只展示来源允许的短摘要与链接，不绕过付费墙抓全文；来源开放访问也不等于任意转载。实际来源、机构标识与全文许可需要分别确认。

新阅读站不含 stepx 的用户手机号、会员、订单、待审修订或管理员凭据。即使仓库设为私有，也不能把含密钥的环境文件或私有备份提交进去。
