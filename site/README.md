# 轻量阅读页

此目录是无需账户、数据库或付费模型的静态阅读界面。请从项目根目录的「打开海洋阅读.cmd」启动，或使用 Python 的 HTTP 服务：

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

再访问 `http://127.0.0.1:8765`。直接双击 HTML 无法通过 `fetch` 载入订阅文件，页面会显示具体提示。

- `index.html`、`styles.css`、`app.js`：原生浏览器页面，无第三方 CDN、追踪脚本或构建依赖。
- `data.json`：由 `scripts/refresh.py` 生成的真实条目与各来源状态，不在页面中塞演示文章。
- `feed.xml`：聚合订阅输出。
- `ocean-sources.opml`：原始 RSS 信源列表，可导入其他 RSS 阅读器；不包含 JSON 或手工来源。

所有资源使用相对路径，可部署于 GitHub Pages 的仓库子目录，本次保留本机阅读。主题标签为规则相关性分类；本轮AI助手已按可获得摘要整理中文标题和总结，依据分别标注为论文摘要、来源节选或仅据标题，不称AI精选或事实审核完成。

中文结果保存在根目录 config/chinese-editorial.json，由更新器按原始标题与摘要的输入指纹匹配。原始英文保留用于检索；新增或内容变化的资料进入待整理队列，默认阅读列表和RSS只显示已整理条目。“也看待整理原文”可查看其他来源记录。采集、刷新和阅读本身不调用模型API。

收藏和已读仅保存到当前浏览器的 `localStorage`。页面可导出 `ocean-bookmarks.v1` JSON 并合并导入；导入最多 1000 条、文件最多 2 MB。格式异常或不安全链接会拒绝整批导入，不覆盖已有收藏；导出文件只在本机生成，不上传到服务器。收藏中的条目即使不再出现在当前订阅文件，仍可在收藏视图中阅读来源链接。

页面通过 `textContent` 渲染来源文字；不使用 `innerHTML`。原文链接仅允许公开 HTTP(S) 地址，拒绝脚本、文件、含凭据或私网目的地；外链使用 `noopener noreferrer`。时间统一以北京时间展示，并区分原文日期、抓取时间及成功时间。抓取失败保留旧记录时，会显式提示。
