页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。网页、RSS、公开 API 与 MCP 均可匿名使用；付费课程与社群是另一套服务，规则见第 6 条。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源明确允许时展示全文，其余只展示摘要、来源名称、原文日期和原文链接。本站不代替原文，也不主张对原文的著作权。

论文与数据的 DOI、航次编号、政策文号等标识由原文提供，本站只做摘录；引用时请以原文和出版方页面为准。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们。我们会在收到后尽快处理：更正条目内容、撤下条目，或按你的要求改为只显示标题和原文链接。下架请求不需要说明理由。

## 3. 使用本站的数据

- **允许**：个人阅读；在注明来源名称与原文链接的前提下引用单条摘要；科研、教学与非商业内部简报中的少量引用。
- **需要事先取得书面同意**：整站或按栏目批量抓取后转载；把本站汇编内容作为付费产品、课程讲义或数据服务的主体；用于训练或微调模型；去除来源标注后再分发。

RSS 与公开 API 的匿名访问是为了阅读和试验，不是批量再分发的授权。同一 IP 每分钟请不超过 60 次；批量同步请注明 User-Agent 并附上来源。

## 4. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口，不提供写入。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。MCP 与 API 的说明见 `/agent`，接口定义见 `/openapi-v1.json`。

## 5. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。信源可能变更、撤稿或更正，本站的摘要不构成科研结论、投资建议、法律意见或政策依据。涉及航行、渔业作业、防灾减灾等实际决策时，请以官方发布为准。

## 6. 课程、社群与付费服务（开设时启用）

如果你通过本站或关联页面购买课程、订阅或社群服务：

- 服务内容、价格、周期和交付方式以购买页面的说明为准；数字内容一经交付，除法律另有规定或页面另行承诺外，不支持无理由退款。
- 付费服务提供的是**整理、讲解与陪跑**，不是对原文的转售，也不构成对科研结论或政策结果的保证。
- 账号、兑换码与课程资料仅限购买者本人使用，不得转售、共享或公开传播。
- 发票、退款与售后请联系上表里的联系方式。

## 7. 变更

本规则更新时会在“更新日志”里说明变更内容；涉及付费服务的实质性变更，会至少提前 7 天在本站公告。
